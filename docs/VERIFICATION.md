# 第一版验证记录

日期：2026-11-11（北京时间）。

## 已验证

- 18项纯计算／备份校验测试：`node --test tests/core.test.cjs`。
- 5项jsdom交互测试：`npm run test:ui`，需先安装开发依赖。此次验证使用独立临时目录中的jsdom 26.1.0，没有给网页添加运行时依赖。
- 主程序与核心计算文件的Node语法检查。
- `node build.cjs`可把运行所需全部静态文件复制至dist目录。

纯计算测试涵盖五项营养、kJ换算、冰衣可食率口径、未知营养字段、动态目标、固定53g、餐次保持、步长导致无解、超钠、最大份量不足、负数等非法输入、自动碳水、A/B/C偏好、穷举目标值交叉校验、快照与备份、求解器返回异常的独立拦截、冲突诊断和多食物营养约束。

交互测试涵盖食品新增／搜索／编辑／删除及HTML转义、自动求三方案、保存／修改／复制套餐、计划与实际互不联动、备份恢复、目标和餐次设置、刷新持久化、应用套餐后实际餐次保持可见、损坏数据不覆盖、无效备份不替换当前数据。
